# Focussive

> **ADHD Focus Session Management & Distraction Blocker System**  
> Cross-platform ecosystem connecting an Android Mobile App, a Chrome Browser Extension, and a Node.js Backend with Supabase PostgreSQL.

---

## 🏗️ Architecture & Monorepo Overview

Focussive is organized as a `pnpm` workspace containing multiple interdependent packages:

```
focussive/
├── packages/
│   ├── mobile/             # React Native (Expo SDK 56) Android app
│   ├── backend/            # Node.js 22 + Express + TypeScript API server
│   ├── extension/          # Vite + React Chrome Browser Extension (Manifest v3)
│   ├── shared/             # Shared TypeScript types, validators, and formatters
│   ├── app-blocker/        # Native Android module (foreground service & overlays)
│   └── installed-apps/     # Native Android module (query installed apps & icons)
│
├── DEPLOYMENT.md           # Unified Build & Deployment Guide (Mobile, Backend, Ext)
├── Procfile                # Heroku deployment process definition
├── fly.toml                # Fly.io container deployment configuration
├── render.yaml             # Render deployment configuration
└── package.json            # Monorepo root workspace scripts
```

## ⚡ Quick Start

### 1. Prerequisites
- **Node.js**: `>= 22.0.0`
- **pnpm**: `>= 9.0.0` (`corepack enable && corepack prepare pnpm@latest --activate`)
- **Android SDK & JDK 17+** (for local Android builds)

### 2. Monorepo Setup
```bash
# Clone and install dependencies across all packages
git clone https://github.com/IBR4H33M/focussive.git
cd focussive
pnpm install

# Compile shared library
pnpm build:shared
```

### 3. Running Services Locally

#### Backend API
```bash
# Start backend in development mode (with ts-node-dev)
pnpm dev:backend
# API runs at http://localhost:8080 (or PORT from .env)
```

#### Mobile App
```bash
# Start Metro bundler & build/run debug APK on connected device/emulator
pnpm build:mobile
```

#### Chrome Extension
```bash
# Start Vite development bundler
pnpm dev:extension
```

## 📱 Mobile App (Android)

Built with **Expo SDK 56**, **React Native 0.85**, and custom native Android modules.

### Internal Structure (`packages/mobile/`)
```
packages/mobile/
├── android/               # Native Android project generated by Expo Prebuild
├── assets/                # App icons, splash screens, and images
├── src/
│   ├── app/               # File-based routing with Expo Router
│   │   ├── (auth)/        # Login, signup, onboarding
│   │   ├── (tabs)/        # Home / Sessions, Analytics, Settings
│   │   └── session/       # Session details, editor, history list
│   ├── components/        # Reusable UI components (SessionCard, modals, etc.)
│   ├── context/           # React Context (AuthContext, SessionContext)
│   └── utils/             # API client, ThemeProvider, reminders, notifications
├── app.json               # Expo configuration & active API endpoint
└── eas.json               # EAS cloud build profiles
```

### Key Mobile Features
- **ADHD Focus Sessions**: Schedule and manage recurring or one-time focus blocks with automatic session status tracking.
- **Native Android Foreground Blocker (`@focussive/app-blocker`)**:
  - Continuous foreground monitoring service (`AppBlockerService`) with `PACKAGE_USAGE_STATS`.
  - System alert overlay (`BlockOverlayActivity`) that interrupts blocked app launches.
  - Emergency breaks with strict budget and countdown enforcement.
- **Persistent Locked Notifications**:
  - **Upcoming Session Reminder**: Soft slate surface (`#7C8CA6`), locked (`FLAG_NO_CLEAR` / `FLAG_ONGOING_EVENT`), dark red countdown timer (`#8B1E1E`).
  - **Running Session**: Deep navy surface (`#1E2235`), locked (`FLAG_NO_CLEAR` / `FLAG_ONGOING_EVENT`), light red countdown timer (`#F87171`).
- **Installed Apps Discovery (`@focussive/installed-apps`)**: Queries user-installed apps and icons via `QUERY_ALL_PACKAGES` to configure blocklists.
- **Browser Extension QR Code Login**: Pair desktop browser extension by scanning the in-app QR code.
- **Harmonious Theme System**: Space Cadet navy, Sage, and Cosmic Latte palette with dark and light mode support.

> [!IMPORTANT]
> Because Focussive uses native modules (`@focussive/app-blocker` and `@focussive/installed-apps`), standard **Expo Go cannot be used**. Always use `pnpm build:mobile` (or EAS dev builds) when testing.

## 🛠️ Monorepo Build Scripts

| Script | Command | Description |
|--------|---------|-------------|
| **`pnpm build:shared`** | `pnpm -F @focussive/shared build` | Builds the shared TypeScript library |
| **`pnpm build:backend`** | `pnpm -F @focussive/backend build` | Compiles the backend to CommonJS `dist/` |
| **`pnpm build:extension`** | `pnpm -F @focussive/extension build` | Builds Chrome extension to `packages/extension/dist` |
| **`pnpm build:mobile`** | `pnpm -F @focussive/mobile android` | Builds & runs local Android debug APK |
| **`pnpm build:mobile:release`**| `pnpm -F @focussive/mobile android:release`| Builds local optimized standalone release APK |
| **`pnpm build:mobile:dev`** | `pnpm -F @focussive/mobile build:dev` | Triggers EAS Cloud development client build |
| **`pnpm build:mobile:preview`**| `pnpm -F @focussive/mobile build:preview` | Triggers EAS Cloud internal preview APK build |
| **`pnpm build:mobile:prod`** | `pnpm -F @focussive/mobile build:prod` | Triggers EAS Cloud Play Store AAB build |
| **`pnpm build:mobile:prod-apk`**| `pnpm -F @focussive/mobile build:prod-apk`| Triggers EAS Cloud standalone production APK build |
| **`pnpm typecheck`** | `tsc --noEmit (workspace)` | Typechecks all packages in the workspace |
